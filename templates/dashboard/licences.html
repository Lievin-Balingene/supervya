1 licence = 1 machine = 1 adresse IP. L’IP est liée automatiquement à l’activation de l’agent.

Recevoir une clé

Votre administrateur Supervya génère une licence pour votre compte. La clé au format SPV-XXXX-… apparaît ci-dessous (état « Générée »).

2

Installer l’agent

Ouvrez la licence : les commandes téléchargent le script depuis GitHub et activent la clé. Aucun port n’est ouvert chez vous — l’agent contacte votre API Supervya.

3
